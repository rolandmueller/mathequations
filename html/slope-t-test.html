t-Test for a Regression Coefficient

t=β^1−0SE(β^1)\htmlClass{term-t}{\textcolor{#8b5cf6}{t}} = \frac{\htmlClass{term-b1}{\textcolor{#10b981}{\hat{\beta}_1}} - \htmlClass{term-null}{\textcolor{#ec4899}{0}}}{\htmlClass{term-se}{\textcolor{#3b82f6}{\mathrm{SE}(\hat{\beta}_1)}}}t=SE(β^​1​)β^​1​−0​

Is there any relationship between X and Y at all? The t-statistic measures how many standard errors the estimated slope lies away from zero, the value it would have if X had no association with Y. The standard error sets the scale: a slope of 0.5 is impressive if its SE is 0.05 and meaningless if it is 1.

Read aloud: t equals beta one hat minus zero, over the standard error of beta one hat.
