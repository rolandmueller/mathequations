Gradient Descent

wt+1=wt−η ∇wL(wt)\htmlClass{term-new}{\textcolor{#8b5cf6}{w_{t+1}}} = \htmlClass{term-old}{\textcolor{#10b981}{w_t}} - \htmlClass{term-lr}{\textcolor{#ec4899}{\eta}} \, \htmlClass{term-grad}{\textcolor{#3b82f6}{\nabla_w}} \htmlClass{term-loss}{\textcolor{#ef4444}{L(w_t)}}wt+1​=wt​−η∇w​L(wt​)

Gradient descent finds good weights by walking downhill on the loss. Starting from the current weights, measure how wrong the model is with the loss, compute its gradient, which points uphill, and take a step of size eta in the opposite direction to get the new weights. Repeat until the loss stops improving.

Read aloud: w t plus one equals w t minus eta times the gradient with respect to w of the loss L at w t.

Definitions

new

Updated weights wt+1w_{t+1}wt+1​. Pronounced: "w t plus one". www stands for all parameters of the model at once (every weight and bias in a network), a vector with possibly millions of entries.

old

Current weights wtw_twt​. Pronounced: "w t". ttt counts update steps. Networks start from small random weights, so two training runs can end in different places.

lr

Learning rate η\etaη. Pronounced: "eta". The most important tuning knob. Too large and the loss bounces around or explodes; too small and training crawls. Typical starting values are 0.001 to 0.01. Optimizers like Adam adapt the step size per weight (optimizer=keras.optimizers.Adam(learning_rate=1e-3)\texttt{optimizer=keras.optimizers.Adam(learning\_rate=1e-3)}optimizer=keras.optimizers.Adam(learning_rate=1e-3)).

grad

Gradient operator ∇w\nabla_w∇w​. Pronounced: "the gradient with respect to w". The symbol ∇\nabla∇ is "nabla" or "del". Turns the loss into a vector of partial derivatives, one per weight: ∇wL=(∂L∂w1,…,∂L∂wm)\nabla_w L = \left( \frac{\partial L}{\partial w_1}, \dots, \frac{\partial L}{\partial w_m} \right)∇w​L=(∂w1​∂L​,…,∂wm​∂L​). Each entry says how much the loss changes when that one weight is nudged. Together they point in the direction of steepest ascent, which is why the update subtracts them. At a minimum the gradient is zero and the updates stop. In a network it is computed layer by layer with the chain rule (backpropagation).

loss

Loss function L(wt)L(w_t)L(wt​), evaluated at the current weights. Pronounced: "the loss L at w t". A single number measuring how wrong the model's predictions are on the training data with weights wtw_twt​: mean squared error for regression, cross-entropy for classification (model.compile(loss="mse")\texttt{model.compile(loss="mse")}model.compile(loss="mse") or loss="categorical_crossentropy"\texttt{loss="categorical\_crossentropy"}loss="categorical_crossentropy" in keras). A regularization penalty such as λ∑wj2\lambda \sum w_j^2λ∑wj2​ is simply added to it. Think of it as a landscape over all possible weights; gradient descent walks downhill on it. For neural networks the landscape has many valleys, so the result depends on the starting point. Plotting the loss after each epoch (the training curve) shows whether training is still improving. Stochastic gradient descent (SGD) evaluates the loss, and so its gradient, on a small random minibatch rather than all the data: noisier but much faster. One pass through all minibatches is an epoch.
