Backpropagation

Training needs to know how much each weight is to blame for the error. The output error is known directly: target minus output. Backpropagation splits it back across the hidden nodes in proportion to the weights that connect them, then repeats layer by layer. Each weight update is a small step in the direction that reduces the error: the error times the slope of the sigmoid times the activation feeding into that weight.

Read aloud: e hidden equals W transpose times e out. Delta W equals eta times e out times o times one minus o, times h transpose.

Definitions

ehid

Hidden-layer error ehidden\mathbf{e}_{\text{hidden}}ehidden​. Pronounced: "e hidden". A hidden node that sends a large weight to an output with a large error gets a large share of the blame. The same step moves the error from layer jjj back to layer j−1j - 1j−1 throughout the network.

wt

Transposed weight matrix W⊤W^{\top}W⊤. Pronounced: "W transpose". The weights between the hidden and output layer, run backwards: transposing swaps the roles of "from" and "to".

eout

Output error eout\mathbf{e}_{\text{out}}eout​. Pronounced: "e out". Target minus actual output, t−o\mathbf{t} - \mathbf{o}t−o, for one training example.

dw

Weight update ΔW\Delta WΔW. Pronounced: "delta W". Applied as W←W+ΔWW \leftarrow W + \Delta WW←W+ΔW (plus, because the error was defined as target minus output). This is gradient descent on the squared error, computed with the chain rule; for hidden-layer weights, use ehidden\mathbf{e}_{\text{hidden}}ehidden​ and that layer's outputs instead.

lr

Learning rate η\etaη. Pronounced: "eta".

deriv

Sigmoid slope o⊙(1−o)\mathbf{o} \odot (1 - \mathbf{o})o⊙(1−o). Pronounced: "o times one minus o". The derivative of the sigmoid, σ′(z)=σ(z) (1−σ(z))\sigma'(z) = \sigma(z)\,(1 - \sigma(z))σ′(z)=σ(z)(1−σ(z)), written in terms of the output o=σ(z)\mathbf{o} = \sigma(z)o=σ(z). ⊙\odot⊙ means element-wise multiplication. Where the sigmoid is flat (outputs near 0 or 1) the slope is tiny and learning stalls: the vanishing gradient problem that ReLU mitigates.

prev

Previous-layer outputs h⊤\mathbf{h}^{\top}h⊤. Pronounced: "h transpose". The activations feeding into the weights being updated. The product of a column (errors) and a row (inputs) gives one update for every weight in the matrix.
