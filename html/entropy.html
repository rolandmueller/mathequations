Entropy (Tree Splitting)

Entropy measures how mixed up the classes in a tree node are, in bits. For each class, take its share in the node and weight it by the log of that share, which is the surprise of drawing that class. A pure node has entropy 0; a 50/50 node with two classes has entropy 1 bit, the maximum.

Read aloud: H sub m equals minus the sum from k equals one to K of p hat m k times log base two of p hat m k.

Definitions

entropy

Entropy of node mmm, HmH_mHm​. Pronounced: "H sub m", or "the entropy of node m". Also written DmD_mDm​ (ISLR). The average number of yes/no questions needed to identify the class of a random observation from the node. With KKK classes the maximum is log⁡2K\log_2 Klog2​K, reached when all classes are equally common. Trees choose the split with the largest drop in entropy, the information gain. Gini impurity behaves almost identically and is slightly cheaper to compute; in practice they rarely produce different trees. pk

Class share p^mk\hat{p}_{mk}p^​mk​. Pronounced: "p hat m k". The fraction of training observations in node mmm that belong to class kkk.

log

Base-2 logarithm log⁡2\log_2log2​. Pronounced: "log base two". −log⁡2p^-\log_2 \hat{p}−log2​p^​ is the surprise of seeing class kkk: 0 bits if it is certain (p^=1\hat{p} = 1p^​=1), 1 bit for a coin flip, 3 bits for a 1-in-8 chance. Since p^≤1\hat{p} \le 1p^​≤1, the log is negative or zero, so the leading minus sign makes entropy non-negative. The base only sets the unit (bits for base 2, nats for ln⁡\lnln) and never changes which split wins.
