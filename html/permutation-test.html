Permutation Test p-Value

p^=1B∑b=1BI(∣Tb∗∣≥∣Tobs∣)\htmlClass{term-p}{\textcolor{#8b5cf6}{\hat{p}}} = \htmlClass{term-norm}{\textcolor{#10b981}{\frac{1}{B}}} \htmlClass{term-sum}{\textcolor{#ec4899}{\sum_{b=1}^{B}}} \htmlClass{term-ind}{\textcolor{#3b82f6}{\mathbb{I}}}\left( \htmlClass{term-perm}{\textcolor{#ef4444}{|T^{*}_{b}|}} \ge \htmlClass{term-obs}{\textcolor{#06b6d4}{|T_{\text{obs}}|}} \right)p^​=B1​b=1∑B​I(∣Tb∗​∣≥∣Tobs​∣)

If the group labels did not matter, shuffling them should not change anything. So shuffle them many times, recompute the test statistic for each shuffle, and count how often it is at least as extreme as the observed statistic. The p-value is that count, summed over all shuffles and turned into a fraction.

Read aloud: p hat equals one over B times the sum from b equals one to B of the indicator that the absolute value of T star b is at least the absolute value of T observed.

Definitions

p

Estimated p-value p^\hat{p}p^​. Pronounced: "p hat". The share of label shuffles that produce a difference at least as large as the real one. No distributional assumptions are needed, only exchangeability under the null hypothesis. A common refinement is 1+count1+B\frac{1 + \text{count}}{1 + B}1+B1+count​, which never reports exactly 0 (the observed labeling is itself one valid permutation).

norm

Normalization 1B\frac{1}{B}B1​. Pronounced: "one over B". BBB is the number of random permutations, e.g. 10000. With small groups all permutations can be enumerated exactly.

sum

Summation ∑b=1B\sum_{b=1}^{B}∑b=1B​. Pronounced: "the sum from b equals one to B". Runs over the shuffles.

ind

Indicator function I(⋅)\mathbb{I}(\cdot)I(⋅). Pronounced: "the indicator of". Equals 1 if the condition inside is true and 0 otherwise, so the sum counts the extreme shuffles. perm

Permuted statistic ∣Tb∗∣|T^{*}_{b}|∣Tb∗​∣. Pronounced: "the absolute value of T star b". The statistic (e.g. difference in means) after randomly reassigning the group labels in shuffle bbb. The absolute value gives a two-sided test.
