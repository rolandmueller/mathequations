A neuron is a small linear model followed by a nonlinear switch. It weighs each input, adds them up together with a bias, and passes the total through an activation function to produce its output. A neural network stacks layers of these, feeding outputs of one layer as inputs to the next.

Read aloud: a equals g of b plus the sum from j equals one to p of w j times x j.

Definitions

a

Activation (output) aaa. Pronounced: "a". The neuron's output, passed on to the next layer. A hidden layer of many neurons computes new features of the input that are learned rather than hand-designed.

act

Activation function ggg. Pronounced: "g". Without it, stacked layers would collapse into one linear model. See the Activation Functions page for the formulas. bias

Bias bbb. Pronounced: "b". Plays the role of the intercept β0\beta_0β0​; it shifts the point at which the neuron switches on. Not to be confused with statistical bias.

sum

Summation over inputs ∑j=1p\sum_{j=1}^{p}∑j=1p​. Pronounced: "the sum from j equals one to p". ppp is the number of inputs. For a whole layer, all neurons are computed at once as a matrix product: a=g(Wx+b)a = g(Wx + b)a=g(Wx+b).

w

Weight wjw_jwj​. Pronounced: "w j". Learned from data by gradient descent. A network with one hidden layer of sigmoid neurons and a single output is a stack of logistic regressions.

x

Input xjx_jxj​. Pronounced: "x j". The jjj-th input: a raw feature in the first layer, or a previous layer's activation. Scale inputs (e.g. standardize) for stable training.
