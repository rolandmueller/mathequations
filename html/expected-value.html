Expected Value

E[X]=∑xx P(X=x)\htmlClass{term-ev}{\textcolor{#8b5cf6}{E[X]}} = \htmlClass{term-sum}{\textcolor{#10b981}{\sum_{x}}} \htmlClass{term-value}{\textcolor{#ec4899}{x}} \, \htmlClass{term-prob}{\textcolor{#3b82f6}{P(X = x)}}E[X]=x∑​xP(X=x)

The expected value is the long-run average of a random quantity. Go through every possible outcome, weight each value by its probability, and add up. For a fair die every face has probability 1/6, so the expected value is (1 + 2 + 3 + 4 + 5 + 6)/6 = 3.5, a value the die can never actually show.

Read aloud: the expected value of X equals the sum over all x of x times the probability that X equals x.
