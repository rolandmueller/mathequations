Bootstrap Standard Error

SE^boot=1B−1∑b=1B(θ^∗b−θˉ∗)2\htmlClass{term-seboot}{\textcolor{#8b5cf6}{\widehat{\mathrm{SE}}_{\text{boot}}}} = \sqrt{\htmlClass{term-norm}{\textcolor{#10b981}{\frac{1}{B-1}}} \htmlClass{term-sum}{\textcolor{#ec4899}{\sum_{b=1}^{B}}} \left( \htmlClass{term-rep}{\textcolor{#3b82f6}{\hat{\theta}^{*b}}} - \htmlClass{term-avg}{\textcolor{#ef4444}{\bar{\theta}^{*}}} \right)^{2}}SEboot​=B−11​b=1∑B​(θ^∗b−θˉ∗)2​

The bootstrap standard error estimates how much a statistic would vary from sample to sample, using only the one sample we have. Resample the data with replacement, recompute the statistic on each resample, and measure the spread of these replicates around their average, averaged with B − 1. It is simply the standard deviation of the bootstrap replicates.

Read aloud: the bootstrap standard error equals the square root of one over B minus one times the sum from b equals one to B of theta hat star b minus theta bar star, squared.

Definitions

seboot

Bootstrap estimate of the standard error SE^boot\widehat{\mathrm{SE}}_{\text{boot}}SEboot​. Pronounced: "the bootstrap S E". Works for almost any statistic (median, IQR, correlation, a regression coefficient), including those with no textbook formula. A 95% percentile interval comes from the same replicates: take their 2.5th and 97.5th percentiles (np.percentile(reps, [2.5, 97.5])\texttt{np.percentile(reps, [2.5, 97.5])}np.percentile(reps, [2.5, 97.5])). The bootstrap assumes the sample represents the population and observations are independent. It struggles with very small samples and with extremes such as the maximum.

norm

Normalization 1B−1\frac{1}{B-1}B−11​. Pronounced: "one over B minus one". BBB is the number of bootstrap resamples, typically 1000 to 10000. It is chosen by you, not by the data, so more is just more computing time.

sum

Summation ∑b=1B\sum_{b=1}^{B}∑b=1B​. Pronounced: "the sum from b equals one to B". The index bbb runs over the bootstrap resamples, not over the observations.

rep

Bootstrap replicate θ^∗b\hat{\theta}^{*b}θ^∗b. Pronounced: "theta hat star b". The statistic θ^\hat{\theta}θ^ computed on resample bbb. Each resample draws nnn observations from the original nnn with replacement, so some appear twice and others not at all (on average about 37% are left out). The star marks "computed on a resample".

avg

Mean of the replicates θˉ∗\bar{\theta}^{*}θˉ∗. Pronounced: "theta bar star". The average of all BBB replicates. If it differs noticeably from the original θ^\hat{\theta}θ^, the statistic is biased.
